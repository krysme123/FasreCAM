# FasreCAM - 面向目标区域的类激活映射方法

> 基于 PyTorch 实现的类激活映射（CAM）改进算法，旨在解决传统 CAM 方法在复杂场景下“激活区域发散、无法精准定位目标”的痛点。本项目为学术论文的配套开源代码（论文准备中）。

## 📖 项目背景

在计算机视觉的可解释性（XAI）研究中，类激活映射（CAM）是解释深度神经网络决策的最常用工具之一。然而，现有方法（如 Grad-CAM, Score-CAM 等）在目标边缘或复杂背景下，经常出现激活区域发散、高亮非目标区域的问题，导致可视化解释不够精准。

本项目提出了一种新的类激活映射方法（FasreCAM），通过改进特征图的加权策略与空间注意力机制，使其能够更精准地聚焦于目标区域，提升了模型解释的定位精度与语义一致性。

## 💡 核心方法

- **目标区域聚焦策略**：在 `base_CAM.py` 中重新设计了特征图的加权逻辑，抑制背景噪声，增强目标区域的激活响应。
- **模块化设计**：代码采用高度模块化的设计，支持即插即用地替换不同的 CAM 基线方法，方便进行对比实验。
- **完整的评估流水线**：提供了从数据加载、模型推理、CAM 生成到结果可视化的全流程测试脚本。
